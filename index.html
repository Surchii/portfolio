🚛 VilotidsApp

SaaS · Pågående

Fullstack SaaS-plattform · Monorepo · Backend + Admin Web + Mobilapp

Java 17 Spring Boot Spring Security JWT React TypeScript Vite Flutter PostgreSQL Docker

SaaS-plattform för transportbranschen som hjälper taxiföretag att hantera förares vilotider och compliance enligt Transportstyrelsens regelverk. Byggt som monorepo med tre separata klienter.

Backend (Java Spring Boot)

  • JWT-autentisering & rollbaserad åtkomstkontroll (Admin / Företag / Förare)
  • Rule engine för vilotidsvalidering enligt regelverket
  • Compliance-beräkning per förare och företag
  • Prenumerationshantering (BASIC / PRO / ENTERPRISE)
  • Schemalagda e-postpåminnelser (Spring Scheduler)
  • Audit logging & plattformsanalytik
  • Skalbar multi-tenant arkitektur

Admin Dashboard (React + TypeScript)

  • Plattformsdashboard med företagshantering
  • Förarstatistik och compliance-översikt
  • Audit-loggvisare och plattformsanalys
  • Rollbaserad åtkomstkontroll i UI

Mobilapp (Flutter)

  • Förarinloggning och daglig aktivitetsregistrering
  • Compliance-kontrollvy
  • Historik och rapporter
  • Cross-platform (iOS, Android, Webb)
